# WhaleLife 抖音子插件

刷推荐流、搜索、看视频片段（画面 + 声音）、读评论、点赞 / 收藏 / 评论 / 关注。挂在「网上冲浪」下面，运行 ID 为 `surf/douyin`。

安装位置固定为 `plugins/surf/sub/douyin`，宿主据此把运行 ID 拼成 `surf/douyin`；仓库目录与 `plugin.yaml` 的 `id: douyin` 保持这一层级关系，商店按 `surf/douyin` 匹配已安装版本。

## 装在哪

```
plugins/surf/sub/douyin/
```

依赖父插件 `surf`（已装）。`abogus`（MIT）随发行包内置在本目录 `node_modules/abogus/`（含 `LICENSE`），全新实例点安装即可启用，无需预装依赖；签名全在本机算，不走任何第三方服务。

## 登录（设置页一键导出）

打开宿主控制台（地址以启动器里显示的为准）→ 插件管理 → 网上冲浪 → 抖音 → 设置，按页面上的四步走：

1. 点「打开登录窗口」——插件用独立配置 `data/browser-profile` 起一个 Chrome 或 Edge（自动探测，也可在「本机连接」里指定路径）并打开抖音，不碰你日常浏览器的登录态。
2. 在弹出的窗口里登录抖音（扫码或手机号）。
3. 回到设置页点「读取并保存 Cookie」——插件通过调试端口直接读回 `douyin.com` 的 Cookie，不用 F12。
4. 显示「已登录」就点「关闭登录窗口」；以后登录过期，重复一遍即可。

**会话归属核实**：只有插件自己启动、且能在该窗口 `localStorage` 对上随机会话标记的专用会话才会被采信；调试端口上已存在但归属无法核实的窗口，不会写入标记、也不会读取登录信息，页面会提示先关闭登录窗口再重新打开专用窗口。打开创作者中心、立即发布、定时/自动发布以及关闭窗口前，都会复用同一套归属核对；归属不明时不导航、不发布、不杀进程，提示重开专用窗口。

不想开窗口时，用「手动粘贴（备用）」：浏览器登录 `https://www.douyin.com/`，F12 控制台 `document.cookie` 复制整段贴进来，保存后点「检查登录」。

Cookie 存在 `data/account.json`，不进日志、不进回执。匿名也能刷到少量推荐，但搜索、详情、评论、互动都要登录。

## 设置项（都在设置页，没有写死在本机）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 调试端口 | `9224` | 登录窗口的 CDP 端口。多个实例同时装本插件时改成不同端口，避免抢端口；改完要关掉窗口再重开。 |
| 浏览器路径 | 空 | 留空自动探测（Windows 找 Chrome / Edge，macOS 找 Chrome / Edge / Chromium）；填了就用填的那个，填了但文件不存在会直接报错，不会偷偷换成别的浏览器。 |
| 窗口模式 | 隐藏 | 可见 / 隐藏（移出屏幕外）/ 无界面；无界面更省资源但更容易被识别为爬虫。 |
| ComfyUI 地址 | `http://127.0.0.1:8188` | 生图服务地址，远程 ComfyUI 直接填 `http://<主机>:<端口>`。 |
| ComfyUI workflow | 空 | API 格式 JSON 的绝对路径，由用户自己填。 |
| 文字卡片标题 | 空 | 自主发布走「纯文字」时渲染到卡片顶部；留空就只有正文，不内置任何文案。 |
| 人设关键词 / 白名单 / 文案池 / 提示词池 | 空 | 全部由用户自己填，插件不读宿主人格或全局配置。 |

`lib/api.ts` 里的网页公共参数（UA、屏幕 1920×1080、24 核、32G、Chrome 版本等）是抓自真实网页的固定模拟设备模板：**跨用户完全一致，不读取也不暴露本机真实硬件**，为了让签名稳定不漂移才固定下来，不需要改。

## 数据都落在插件自己目录

`data/` 下的 `account.json`（Cookie）、`device.json`（设备指纹）、`seen.json` / `auto-feed.json` / `auto-publish.json` / `publish-queue.json`（运行缓存）、`browser-profile/`（专用浏览器配置）全部由插件自己读写；发行包与源码仓库都排除 `data/`，卸载或换机器不会带走别人的登录态。

| `douyin_view` | 看某条视频的片段：抽帧交给主模型，声音开关打开时转写语音 |

| `douyin_user` | 看作者的作品列表 |
| `douyin_binge` | 连着刷几轮 + 顺带看前几条，适合“自己刷一会儿” |
| `douyin_interact` | 点赞/收藏/关注/评论，需开关 + full 权限 |

## 发布（对外可见）

设置页「现在」卡片有两个按钮：

- **现在刷一条**：随机刷一条推荐，直接把文案、作者、点赞数显示出来。
- **现在发一条**：展开表单，填作品描述、图片本地路径（每行一个，最多 9 张）或 ComfyUI 提示词、发布时机（留空立即发，填 `YYYY-MM-DD HH:mm` 就进定时队列）。
- **发短视频**：在同一个表单里填「视频本地路径」，与图片互斥；填了视频就走创作者中心的「发布视频」页签，**等转码出可播放预览之后才点发布**，不会把没转好的视频提交上去。

发布走的是创作者中心的真实网页流程：插件在登录窗口里打开 `creator.douyin.com`，注入图片、填入描述、点「发布」。不绕过平台校验，被拦就如实报错。

前置条件：设置页勾上「允许发布」；登录窗口开着，里面已经登录你自己的创作者中心账号。

**ComfyUI 生图**：填 ComfyUI 地址（默认 `http://127.0.0.1:8188`）和一个 **API 格式** workflow JSON 的本地路径。界面格式的 workflow 需要在 ComfyUI 里用「Save (API Format)」导出。占位符 `{{PROMPT}}` 会被替换成提示词；没有占位符时替换第一个 `CLIPTextEncode`。

**定时发布**：任务存在 `data/publish-queue.json`，插件每分钟检查一次；到点若窗口没开会自动拉起窗口再发。宿主重启后队列仍在。

**纯文字卡片**：用本机 PowerShell + System.Drawing 渲染成 1080×1440 的图（Windows 自带，不装额外依赖）；字体按 微软雅黑 → 黑体 → Arial 顺序回退，标题取自设置页，没填就只有正文。非 Windows 环境缺 `powershell.exe` 时会直接报错，不会静默降级。

**风控提示**：发布、读作品之前会先看当前页面上有没有短信验证或滑块/安全验证；挂着就直接报 `verify_required` 并让你去窗口里手动过一次，不会带着验证码硬点按钮。设置页「窗口状态」那行也会显示当前验证码状态。

**作品核对**：`douyin_works` 打开「我的」页的作品网格读取作品 ID / 类型 / 标题，只读不点任何按钮；发布完可以用它确认作品真的在号上。

**回评论**：抖音网页版没有能直调的回复接口，所以走页面操作——打开作品页、展开评论区、在目标评论上点「回复」、写进编辑框、点「发送」，最后回读页面确认自己那条在不在。

- 手动：用 `douyin_reply`，给作品 ID、回复内容，再给 `match`（评论正文片段或作者昵称）或 `index`（下标）定位。匹配到多条会拒绝并要求用 `index`。
- 自动：设置页「回评论」卡里填模板（每行一条，随机选，支持 `{author}`），打开开关就每 30 分钟回一轮；只扫最近几条作品的一级评论，作者自己的评论不回，同一句回复不会重复发（按评论 ID 或「作者+正文」哈希去重）。
- 护栏：要同时打开「允许发表评论」；每小时有硬配额；撞到短信验证或滑块会**停 6 小时**并如实告诉你，不会带着验证码硬点。

**边界**：抖音没有“纯文字”发布，最长的是「发布文章」（支持 2 万字图文，仍需配图）。发布是对外可见的真实操作，插件不会自己在没开关的情况下发任何东西。

## 边界

- 视频只走 `aweme/v1/play` 网关下载低码率片段（CDN 直链带 webid 校验会 403）。默认片段上限 24 MB、单次最多 60 秒。
- 只看采样画面和区间语音证据，不等于完整观看。
- 遇到平台验证/风控会直接报 `risk_control` / `access_blocked` 并停下，不换账号、不伪装设备绕过。
- 互动默认全关；开关只能从设置页开，模型不能自己开。
- 平台接口属于当前可观测实现，抖音改版后需要按实际返回修正。
